# 隔离执行提供方

状态：**固定操作适配组件开发中，尚未完成跨平台宿主运行与生命周期验收**。组件存在不代表完整隔离执行提供方已交付。

## 接入与边界

本目录提供受信同进程工具适配导出，不提供独立 Cordis 服务、模型选路或自由命令工具。固定操作通过官方 `load_workspace_dependencies` 与 `bash` 注册器执行，保留实际 Agent、root/parent、signal、权限、沙箱、超时与取消。

领域调用方负责先授权实际任务。插件只接受受信注册配置中的操作与依赖身份，不接受模型、上传文件或浏览器传入任意脚本、包路径或版本。页面和 Agent 工具共用相同领域服务与授权边界。

开发前阅读[仓库规则](../../../apps/web/AGENTS.md)、[架构](../../../apps/web/docs/ARCHITECTURE.md)、[契约](../../../apps/web/docs/CONTRACTS.md)和[验收要求](../../../apps/web/docs/ACCEPTANCE.md)。

## 锁定依赖与运行

`src/locked-package.mjs` 校验受信插件注册的离线 Python 包：固定 manifest SHA-256、逐 wheel 校验、依赖锁一致性、平台/Python/系统版本及受控文件名。注册目录和摘要只能来自受信安装制品。单次文件校验不代表后续字节不可变。

执行前重新校验并复制 wheel 字节到新的临时环境，使用无索引、哈希锁定安装与 Python isolated 模式，结束后清理。共享运行时保持只读，不安装或替换共享依赖。当前仅支持小输入（32 KiB）和完整前台输出；输出截断或转后台不能标为成功。

manifest v2 的显式宿主依赖切片仅支持固定 NumPy 2.3.5，其余离线制品只允许纯 Python wheel。通过官方公开工具发现宿主依赖，计算前后核验内容摘要；适用平台还需核验原生扩展、动态库与解释器的签名兼容。限定导入范围，不无差别继承共享 `site-packages`，不静默切换 PATH Python 或重新安装同名宿主依赖。

实际依赖摘要进入结果 provenance。依赖缺失、版本不符、来源越界、签名不兼容、取消、超时或输出截断均明确失败；面向用户只返回有界错误分类，不泄露原始 stderr、运行时路径或业务数据。不通过去除签名、重新签署已安装解释器或关闭 library validation 绕过不兼容问题。

## 当前限制

- 不提供任意宿主依赖复用、长期环境复用或后台作业结果接收。
- 解释器单文件哈希不等于完整运行时及原生依赖闭包身份。
- NumPy 可用不代表依赖 SciPy 等额外模块的操作已可执行；每项操作需声明并验证数值范围。
- 源码和单元测试不能替代真实宿主、升级失效、损坏恢复、取消与跨平台安装验收。

需要增强公开依赖身份契约时，由 QuantDSH 平台协调；领域插件不读取官方内部状态，也不修改已安装运行时。
